📝 PROCÉDURE DÉTAILLÉE
======================================================================

Voici une procédure SQL pour récupérer une table supprimée ou modifiée dans Oracle, basée sur votre scénario. Cette procédure utilise des fonctionnalités comme Flashback Transaction History et Flashback Table pour restaurer la table à un moment précisé avant l'incident.

### Procédure de Récupération

```sql
-- Définir le timestamp du problème
DECLARE
  incident_timestamp TIMESTAMP := TO_TIMESTAMP('2024-01-15 10:00:00', 'YYYY-MM-DD HH24:MI:SS');
BEGIN
  -- Vérifier si Flashback est activé
  DBMS_FLASHBACK.SET_TRANSACTION(incident_timestamp);
  
  -- Utiliser Flashback Transaction History pour récupérer la table
  EXECUTE IMMEDIATE 'FLASHBACK TABLE "EMPLOYEES" TO TIMESTAMP :1'
    USING incident_timestamp;
END;
/
```

### Explications

1. **Définir le timestamp du problème** :
   - `incident_timestamp` est défini avec une date et heure spécifique (2024-01-15 10:00:00).

2. **Flashback Transaction History** :
   - La procédure utilise la fonction `DBMS_FLASHBACK.SET_TRANSACTION()` pour définir le timestamp de l'incident.
   - Puis, elle utilise une commande EXECUTE IMMEDIATE avec Flashback Table pour récupérer la table à un moment précisé avant l'incident.

### Notes Importantes

- **Flashback Transaction History** est généralement utilisé lorsque vous voulez restaurer une transaction spécifique. Cependant, dans votre cas, nous cherchons à récupérer une table entière à un timestamp précis.
  
- Si la table a été supprimée ou modifiée par une autre transaction après l'incident, Flashback Transaction History ne pourra pas récupérer cette information.

### Alternatives

Si Flashback Transaction History n'est pas applicable dans votre cas (par exemple, si la table a été modifiée par une autre transaction), vous pouvez utiliser **Flashback Table** avec un timestamp spécifique :

```sql
-- Utiliser Flashback Table pour récupérer la table à un moment précisé
EXECUTE IMMEDIATE 'FLASHBACK TABLE "EMPLOYEES" TO TIMESTAMP :1'
  USING incident_timestamp;
```

### Conclusion

La procédure ci-dessus utilise Flashback Transaction History pour récupérer une transaction spécifique, mais si vous voulez récupérer une table entière à un timestamp précis, vous pouvez utiliser Flashback Table directement. Assurez-vous de vérifier les conditions spécifiques de votre environnement Oracle avant d'exécuter ces commandes.
